# 目标包边界

`cmd/strmgen` 装配 CLI 与同步入口。`internal/openlist` 负责 API；`pathmap` 负责路径与稳定 URL（纯函数）；`strm` 负责版本 1 协议解析、序列化与比较（纯函数）；`storage` 负责 SQLite 最小归属／轮次；`reconciler` 负责目录对账、有界遍历、跨进程互斥与原子发布。

当前实现范围（Task 1.1）：首次生成、最小归属登记、重复运行跳过、同哈希 Size 异常记录、需更新时保留原文件并非零退出、dry-run 零持久化副作用、跨进程单轮互斥。尚未实现：已拥有文件的内容替换、Mirror 删除／移动清理、serve／定时、发布镜像。依赖从接口注入；协议／路径纯函数不执行网络或数据库操作。
