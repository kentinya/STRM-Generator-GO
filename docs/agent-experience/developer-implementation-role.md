# Developer：实施

执行方法见 [流程](../development-workflow.md)，边界见 [AGENTS](../../AGENTS.md)。

在活动 Task 内实现、修复、验证并提供真实实现 SHA／原始证据；不扩大合同，不把工具 smoke 当产品验收，不签发自己的独立审查 PASS。

Slice 1 复盘：

- 只识别完整暂存会让正常中断永久冲突，恢复后跳过又可能绕过目录 sync → 沿用归属与可识别暂存依据处理未写／半写残留，并在每条恢复目录变更成功路径传播 sync 失败 → 适用于正常单写者更新恢复，不增加独立媒体状态机或自动认领。

Slice 2 复盘：

- 本轮暂存缺失证据可能在当前重核出现后残留 → 让出现观察同时清除私有 pending 记录，并以不同完整 epoch 的提交事务累加计数 → 适用于有界对账、删除重核和重启恢复，避免失败轮或同轮先后顺序制造删除资格。

Slice 4 复盘：

- 恢复入口误把已修改的当前配置当成原值 → setup 保存原始前值，恢复缺失前值时明确拒绝回退，并逐字段确认实际恢复 → 适用于临时缩小真实验收范围的薄取证工具，不扩建通用恢复平台。
