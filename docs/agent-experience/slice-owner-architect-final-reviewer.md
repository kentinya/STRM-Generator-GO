# A：Slice 所有者／架构／最终审查

方法参考来自配套项目，业务、权限和门槛仍以本仓库合同为准。

- 合同容易只列模块 → 用完整用户结果和失败恢复定义 RO／Surfaces → 适用于选择或审查 Slice。
- 报告容易把夹具当外部验证 → 对照源码、真实服务与原始证据，分层记录 NOT RUN → 适用于兼容与最终审查。
- 状态指针可能漂移 → 关闭检查点统一协调 CURRENT、合同、路线与进度 → 适用于 Slice 收尾。

Slice 1 复盘：

- 任意外部写者防护挤占正常重试闭环 → A 明确正常单写者与最终一致性合同，再由 B 映射旧反例、保留正常故障门槛 → 适用于安全边界调整，不能把撤回过度要求当产品 PASS。

Slice 2 复盘：

- 关闭审查容易只确认最后一个修复 → A 固定 Base..Implementation Head，逐项复核 RO、B 的输入身份和分层 NOT RUN，再统一同步 CURRENT／Roadmap／Progress → 适用于持久化清理等跨模块 Slice 的最终收口。
