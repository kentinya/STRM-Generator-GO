# B：Task 规划／审查

- 文件拆分容易掩盖跨资源风险 → 先读真实仓库，按成功／失败／恢复闭环规划 → 适用于首次原型与持久化工作。
- 文档摘要可能不等于候选 → 审查完整 Base..Head 和输入匹配的原始证据 → 适用于独立 Task Review。
- 已满足能力仍不断追加任务 → 每次 PASS 重评全部 RO，P2独立记录 → 适用于决定继续或提交最终审查。

Slice 1 复盘：

- 既有全绿未覆盖根目录共享游标和半写窗口 → 用同一 prepared root 多目标、由 Update 自己产生的 0／半写残留及发布二进制重启补充独立复现 → 适用于目录句柄与跨资源恢复审查；屏障不代表目录已持久化。

Slice 2 复盘：

- 简化远端缺失规则仍需证明完整轮边界 → 用真实固定服务的源根／目标 Get 与发布 CLI 闭环分层回放，单独核对 refresh:false、三轮资格和下一轮重核 → 适用于用户主动接受错误原因不细分的清理合同。

不得由实施者扮演独立审查者自签 PASS。
