# 范围

[V4.3 原方案](<../STRM Generator Go.md>) 原样保留，内容身份固定在 [环境规范](../dev/environment-spec.json)。配套项目只读 STRM；本项目维护 STRM。两者共享文件协议，不共享状态库、调度器或内部接口。

开发准备基线已交付：中文需求／架构／合同、API 夹具、质量检查、CI、固定 Go 工具链与交接。用户随后要求激活 Slice 1「安全的单轮生成闭环」，当前以其 ACTIVE 合同限定范围；当前实施单元见 [TASK.md](../TASK.md)。Task 1.1 的 `sync`／`sync --dry-run` 基线已获 B PASS；Task 1.2 的最新内容更新候选 `d0e2bac` 经 B 独立复审仍为 FIX REQUIRED：最终检查后的清理仍可删除外部对象；第一次恢复会消费唯一冲突证据，下一次同步仍覆盖合法外部 STRM；最后检查后的暂存替换仍可误发布；绑定根目录游标共享还使后续文件漏检恢复残留。修正留在同一 Task，不能把有可执行文件或既有场景通过视作 Task 或 Slice 验收通过。

产品范围：OpenList list／get 元数据；稳定 `/d/` URL；版本化 STRM；目录镜像；增量比较与原子更新；SQLite 最小归属／轮次；经过完整成功对账的安全清理；单轮互斥、有界目录并发；手动／预览／定时；Linux amd64／arm64 容器与二进制；最终一致性和分层验收。

2026-10-18 用户授权 A 限制外部写者：本地输出／暂存／状态由生成器单写者维护，消费者只读，所有生成器共享同一锁资源；具体为需求 SW-1..SW-6。此限制贯穿轮次间与恢复，不承诺抵御同 UID／root 或任意不合作写者。属于显式合同修订，不表示旧失败已修好；启动已知条件校验、未知残留保护、目录枚举和 T4 尚须在 Task 1.2 完成。既有未归属保护、原协议／比较规则／SQLite 边界不变；不自动变更生产权限，不扩展为内核仲裁或权限管理系统。

排除：实时一致性保证、独立发现或媒体版本状态机、下载媒体计算哈希、生成签名临时链接、ffprobe／转码、修改 Jellyfin 数据库或代理、触发插件内部任务、三组件自动串行编排、保留移动后的 Jellyfin Item ID／媒体流保证。

方案中的十万至百万规模是目标；512 MB 是初始压测限制，尚无内存或吞吐承诺。真实数据源配置、访问身份、挂载的 `/d/` 无签名可用性、媒体扩展名与 SQLite／YAML 依赖版本，应在相应 Task 用实证确定，不自动借用生产环境。
